## v0.3 — GeoParquet inventories

October 2, 2026

Save STAC metadata for your study area, then search it again without downloading
the same metadata each time. Use automatic mode to query live catalogs when your
saved data is too old or doesn’t cover the search.

GeoParquet is available in Python, Rust, and the CLI. Ingestion shows progress and
can resume after an interruption. You can also update an inventory and clean up
old files. Imagery and previews still come from the provider.

[Try the notebook](/docs/v0.3/python/geoparquet-notebook) or follow the
[GeoParquet guide](/docs/v0.3/guides/geoparquet).

**Upgrading:** Python wheels include GeoParquet. For Rust and the CLI, enable the
`geoparquet` feature. Existing version-1 inventories remain readable; writing an
update upgrades their manifest to version 2, which older builds cannot read.

## v0.2 — Python support

September 27, 2026

Use SuperSTAC from Python scripts and notebooks, with synchronous and asynchronous
clients, dictionary results, and collection discovery. This release also introduced
the documentation site and installable wheels for Linux, macOS, and Windows.

The Python package replaced the v0.1 alpha implementation. If you used that version,
start with the [Python guide](/docs/v0.3/python/overview) to switch to the new API.

See the [changelog](https://github.com/spatialnode/superstac/blob/main/CHANGELOG.md)
for individual changes, or [GitHub releases](https://github.com/spatialnode/superstac/releases)
for downloads.
