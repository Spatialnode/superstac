description: Save Sentinel-2 metadata around Madrid and search it locally.

Try GeoParquet with a small Sentinel-2 inventory around Madrid. The notebook walks
through saving metadata, searching it locally, and using live catalogs when a
query falls outside the saved area or dates.

[Open in Google Colab](https://colab.research.google.com/github/Spatialnode/superstac/blob/main/docs/public/versions/v0.3/notebooks/superstac-geoparquet.ipynb)
or <a href="/superstac/versions/v0.3/notebooks/superstac-geoparquet.ipynb" download>download for Jupyter</a>.

You’ll see ingestion progress, filter and sort results, and optionally display an
imagery thumbnail. Later cells cover adding more dates, updating the inventory,
compacting files, and exporting a ZIP.

The notebook uses SuperSTAC v0.3.x. You need internet for installation, provider
requests, and previews; the default catalog needs no API key or GPU. Only metadata
is saved, so you won’t be downloading full satellite images.

**Using Colab?** Download the inventory ZIP before ending your session; runtime
files are temporary.

For commands and options, see the [GeoParquet guide](/docs/v0.3/guides/geoparquet).
