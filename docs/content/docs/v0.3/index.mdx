**Many catalogs. One search.**

Search several STAC catalogs with one query. Add the catalogs you use, choose an area and date range, and get their results together.

Try it in your browser, use Python in a notebook or script, add Rust to your application, or work from the command line. SuperSTAC searches catalogs in parallel and reports which ones failed, so you can check whether the results are complete.

## What you can build

Find imagery across catalogs, use consistent collection and band names, or check which datasets a catalog offers. If you often search the same area, [save its metadata to GeoParquet](/docs/v0.3/guides/geoparquet) and reuse it. Results contain STAC metadata and asset links; use your usual tools to download and process imagery.

## Before you start

Start with [installation](/docs/v0.3/start/installation), then [run your first search](/docs/v0.3/start/quickstart). SuperSTAC is **alpha software**: APIs may change, and some search features are [not yet supported](/docs/v0.3/reference/status).

## Choose your interface

| Interface | A good fit for |
| --- | --- |
| [Browser / WASM](/docs/v0.3/wasm/overview) | JavaScript and TypeScript apps that search live catalogs. |
| [Python Client](/docs/v0.3/python/overview) | Notebooks, scripts, and synchronous pipelines. |
| [Python AsyncClient](/docs/v0.3/python/async) | Applications that already use asyncio. |
| [Rust engine](/docs/v0.3/rust/overview) | Native integrations on Tokio. |
| [CLI](/docs/v0.3/cli/overview) | Terminal exploration and shell workflows. |

## What works where?

| Capability | Python | JavaScript / WASM | Rust | CLI |
| --- | --- | --- | --- | --- |
| Live search and collection discovery | Yes | Yes | Yes | Yes |
| Collection and asset aliases | Yes | Yes | Yes | Yes |
| Retries, timeouts, deduplication | Yes | Yes | Yes | Yes |
| GeoJSON geometry filter | Yes | Yes | Yes | Bounding box only |
| Source catalog on each returned item | Not exposed | Yes | Yes | JSON output |
| Saved GeoParquet inventories | Included in wheels | No | Optional feature | Optional feature |
| YAML configuration | Yes | No | Yes | Yes |

SuperSTAC returns metadata and asset links. Image rendering in the playground is a separate feature. For current limits, see [status and limitations](/docs/v0.3/reference/status).
