# SuperSTAC logo

One entry point branches into three overlapping map sheets with simple contour curves.

- `superstac-logo.svg`: charcoal for light backgrounds.
- `superstac-logo-dark.svg`: white for dark backgrounds.
- `superstac-logo.png`: original approved raster artwork, generated with the built-in image generation tool.

The SVGs trace the approved artwork into matching vector paths, including the lettering. They have transparent backgrounds and require no fonts. The root README selects the appropriate SVG using a `<picture>` element with `prefers-color-scheme`. Documentation sites with manual theme controls should select the asset matching their active theme.
