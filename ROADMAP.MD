# SuperSTAC Roadmap

Our priority is reliable federated STAC search. These are areas of focus,
subject to feedback and capacity, with no fixed delivery dates.

## Short term

- Fix search and iterator edge cases, backed by focused tests.
- Improve configuration errors, logging, and documentation.
- Support private catalogs through custom headers and environment-based credentials.

## Near term

- Add catalog preferences and improve health-based fallback.
- Introduce SQLite persistence.
- Improve pagination and result handling across Python, Rust, and the CLI.

## Long term

Explore broader authentication, additional storage backends, and ecosystem
integrations as real use cases emerge.

## v1.0 release

- Stable public APIs and configuration format.
- Well-tested core search, with predictable results and failure handling.
- Clear documentation, supported-platform coverage, and migration guidance.

The v1.0 release depends on core stability; longer-term ideas are optional.
